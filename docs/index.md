# KUISC Knowledge Base

Welcome. This is the archive and reference site for KU Information Security Club:
meeting notes, onboarding material, CTF writeups, internal tooling, infrastructure
docs, playbooks, and past presentations.

## Where do I start?

- New member? Go to **[Onboarding](onboarding/index.md)**.
- Looking for a past talk or slide deck? See **[Presentations](presentations/index.md)**.
- Setting up a competition environment? See **[Infrastructure](infrastructure/index.md)**
  and **[Playbooks](playbooks/index.md)**.
- Want to build/run a club tool? See **[Tooling](tooling/index.md)**.

## How this repo is organized

| Folder | What goes here |
|---|---|
| `onboarding/` | New-member guide, expectations, accounts to set up, gear to install |
| `meetings/` | Per-meeting notes, agendas, recordings/links |
| `ctf/` | Writeups from competitions, organized by event |
| `tooling/` | Custom scripts/tools the club has built, with usage docs |
| `infrastructure/` | Terraform for club infra, VM image docs and download links, network diagrams |
| `playbooks/` | Step-by-step guides — e.g. "set up a CCDC scoring engine," "spin up a vuln box" |
| `presentations/` | Slide decks and recordings from meetings/speakers |

See [Contributing](contributing.md) for how to add material.
