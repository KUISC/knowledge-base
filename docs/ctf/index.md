# CTF Writeups

Writeups organized by competition/event. Create a subfolder per event:

```
ctf/
  2026-ccdc-regionals/
    index.md
    web-challenge-1.md
  2026-picoctf/
    index.md
    ...
```

Each writeup should cover: challenge description, approach, solution, and
takeaways/lessons for next time.
